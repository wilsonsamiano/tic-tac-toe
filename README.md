# Tic-Tac-Toe

Installable tic-tac-toe. Play against the AI, pass the phone, or start an online game with a 6-character code.

Open `index.html` to play. To host it, turn on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**. The site will be https://wilsonsamiano.github.io/tic-tac-toe/

MIT licensed. [Buy me a coffee](https://buymeacoffee.com/wilsonsamiano)

## What it does

- Versus AI on Easy, Medium, or Hard (Hard uses minimax and will not lose)
- Two players on one device
- Online multiplayer with a share code
- Midnight, Light, Neon, Sunset, and Camo themes
- Scoreboard saved on this device
- Add to Home Screen (iPhone and Android)

## Run it

Open `index.html`, or serve this folder with any static host. Relative paths are used so it also works from GitHub Pages.
